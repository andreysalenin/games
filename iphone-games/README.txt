The four games on iPhone
========================

This folder is a small website: a start page and the four games (momo, lou, pipoca, cora).
Put it online once, then add each game to the iPhone's Home Screen from Safari.

1. Put the folder online with GitHub Pages (free, adds nothing to the pages)
   On a computer:
   a. Sign in at github.com, or create a free account.
   b. Click + (top right), then New repository. Name it "games", leave it Public,
      and click Create repository.
   c. On the new repository's page, click "uploading an existing file".
      Unzip this file and open the "iphone-games" folder. Select everything inside it
      (index.html, README.txt and the four game folders) and drag it onto the page.
      When all the files are listed, click Commit changes.
   d. Click Settings, then Pages in the left column. Under "Build and deployment", set
      Source to "Deploy from a branch", choose the branch "main" and the folder "/ (root)",
      and click Save.
   e. After a minute or two, reload that page. It shows the address at the top, normally
      https://YOUR-GITHUB-NAME.github.io/games/
   Any other web host works too: upload the contents of the "iphone-games" folder as they are.

2. Add the games on the iPhone
   Open that address in Safari and tap a game. Then tap ••• next to the address bar,
   Share, Add to Home Screen. Leave "Open as Web App" on and tap Add.
   Open the game once from its new icon while you have internet; after that it works
   without internet. The start page repeats these steps.

Good to know
- The site holds only the games. Anyone who has the address can open them; your child's
  name and progress stay on the iPhone.
- Each Home Screen game keeps its own progress. Removing its icon erases that progress.
  A game added from a different address (for example an earlier copy on another host) is a
  separate app with its own progress.
- To update a game later, upload the new files to the same repository (Add file, then
  Upload files, then Commit changes). A game picks up the new version after it has been
  opened once or twice with internet.
